# The Meeting That Should Have Been an Email

One line, at most 200 characters, that makes a meeting-that-should-have-been-an-email funny: someone shares their screen to read aloud an email everyone had already read. One concrete image, no setup, no explanation — the turn lands on the last word.

## Run it

```sh
python3 main.py
```

Writes the single-line entry to `/output/entry.txt` (Python 3.13 standard library only, no network). The program asserts the output is exactly one line, 1–200 characters, and non-empty before writing.
